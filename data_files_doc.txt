DataFile
InvFile
These classes are used to manage .DAT and .INV files
for reading game data and reading and writing player
inventories. In most cases, if a user just needs to add an
item they don't need to use these InvFile methods
directly — they can use the player.additem() helpers
described in the player documentation .

The user's inventory for a given item type. Lists what
items they have, the count of each, and the condition of
each item.

inv.sync()
Method
Flushes any modifications to disk. W on't write if there
were no changes. Should only be called when the page
exits via remove(), or as infrequently as possible to
reduce disk thrashing.
