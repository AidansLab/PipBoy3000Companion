All player methods are related to setting particular values
about the user and their inventory.
Player Methods
player.sync()
Method

---PAGE BREAK---
Saves any modified and persistent player attribute values
to disk. Shouldn't be called too frequently to avoid
thrashing the SD card. If you make a page that uses the
player class and you set attribute values that should be
persistent, call this in the remove() function of your app
to flush them to disk.

player.resetinventory()
Method
Resets all inventory items back to their default inventory
state for both F allout 3 and New V egas game modes.
player.calculateInvWeight()
Method
Recalculates the player wg value — the total mass of all
items in their inventories. Users probably won't need this.

player.setav(av, value,
persist)
Method
The set version of player.getav(). Takes an attribute
value name and the value to set it to.
The optional third parameter persist is non-standard
(not in the game commands). If set to true, the value
will be persisted to disk when player.sync() is called.
Defaults to false. It's best not to persist unless you
really need something to survive a reboot.

player.addperk(formId)
Method
Adds a perk by its form ID. The formId is a numeric
value and can be passed as hex to match game
conventions.

---PAGE BREAK---
Which perk IDs are valid depends on the current game
mode of the Pip-Boy. If it's in New V egas mode, it'll take
New V egas perk IDs and add them to a New V egas
specific version of PERKS.JSON. Both player.addperk()
and player.removeperk() modify values in mode-
specific PERKS.JSON files.
Paramet ers
Name Type Default Descr iption
formIdnumber —The perk's form ID
(e.g. 0x00031DC4 for
"Computer Whiz")
